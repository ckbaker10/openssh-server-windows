# OpenSSH Server für Windows

Ziel ist ein unter Linux crosskompilierter OpenSSH-Server für modernes Windows, ohne Microsoft-SDK. Die benötigte Cygwin-Laufzeit darf mitgeliefert werden.

Die [Recherche zu Portierungen und Buildmöglichkeiten](docs/openssh-windows-recherche-2026-10-19.md) empfiehlt OpenSSH Portable mit einer Cygwin-Cross-Toolchain für Windows x86_64.

Das Projekt enthält zunächst die Recherche. Ein erfolgreicher Cross-Build und der Serverbetrieb auf Windows müssen noch erprobt werden.
